## Current product state (authoritative — May 2026)

Use this block for how the game works **now**. Entries below are a historical dev log and may describe removed UI.

- **Player flow:** Daily GP lobby → **Start Race** → single-lap (or configured objective) on the challenge track → result modal → retry or back to lobby.
- **No track picker** in `game.html`: the old returning-player carousel / `game/ui.js` track selector is gone.
- **No per-track mode select** in the live client (Time Trial / Session picker was removed with that flow).
- **Track source:** `activeDailyChallenge.trackKey` from the Reddit API; server builds the day in `src/server/daily-gp-model.ts` (fixed `cedarRidgeCircuit` today).
- **`CONFIG.visibleTrackKeys`:** server allowlist + tests only—not shown to players.
- **`TRACKS` in `game/track/tracks.js`:** all circuit data; dev tools (mapmaker, runner, tiktok-studio) list every key.
- **Docs:** [README.md](README.md#how-the-game-works-today), [CHANGELOG.md](CHANGELOG.md#current-product-authoritative).
