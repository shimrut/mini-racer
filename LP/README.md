# Mini Racer landing page

Standalone promo page. Open `index.html` in a browser, or host the whole `LP` folder anywhere.

## Set the links

Edit `config.js` and paste the Daily and Campaign post URLs:

```js
window.LP_LINKS = {
    daily: 'https://…',
    campaign: 'https://…',
};
```

Empty values leave that button disabled.
